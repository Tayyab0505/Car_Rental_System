# DriveEase - Car Rental Management System

## Overview

DriveEase is a full-stack MERN car rental platform with separate Admin and User panels.

## Features

- JWT Authentication
- Role-Based Access Control
- Car Management
- Booking Management
- Advanced Filtering
- Dark/Light Mode
- Responsive Design

## Tech Stack

### Frontend

- React
- Tailwind CSS
- Axios
- React Router DOM

### Backend

- Node.js
- Express.js
- Sequelize ORM

### Database

- PostgreSQL

## Installation

### Frontend

npm install
npm run dev

### Backend

npm install
nodemon server.js
